# hydrogen

Ever wanted to use [libhydrogen](https://github.com/jedisct1/libhydrogen) in your project, but frustrated because it has a bunch of source files across multiple directories?

Here it is, collapsed into hydrogen.h and hydrogen.c so it's super easy to just drop in to your project.
